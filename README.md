# MealWise — Smart Canteen Food Waste Prediction and Management System

## Overview
MealWise helps canteen administrators predict food demand, estimate waste, track sales,
and make data-driven preparation decisions.

## Roles
- **Admin** — manages food items, inventory, sales, waste records, predictions, and analytics.
- **Student** — views menus, prices, and real-time availability.

## Tech Stack
| Layer        | Technology                                      |
|--------------|-------------------------------------------------|
| Frontend     | React.js, Vite, JavaScript, React Router, CSS   |
| Backend      | Python, FastAPI, SQLAlchemy                     |
| Database     | PostgreSQL + pgvector                           |
| Migrations   | Alembic                                         |
| ML           | Pandas, NumPy, Scikit-learn                     |
| AI / RAG     | Document retrieval, Embeddings, LLM API         |
